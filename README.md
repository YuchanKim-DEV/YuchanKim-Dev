### Project 2. STT 솔루션 납품

`2026.02 ~ 2026.06` &nbsp; 실시간 음성 스트림 수신 TCP 서버 · STT 결과 전달 컨슈머 · 최대 480채널 · AWS

- **STT 엔진 부하 쏠림 해소 — 최고 CPU 200% → 80% 이하**<br/>
  gRPC 장기 연결이 L4 로드밸런서 뒤 한 서버에 고정되는 원인을 찾아, 통화를 끊지 않는 연결 회전 방식으로 재분산
- **결과 전달 지연 해소 — 처리 대기 1만 건 이상 → 평시 0건**<br/>
  동기 호출을 비동기로 전환하고, 끊긴 연결 재사용과 유휴 연결 종료 문제를 함께 해결

### Project 3. STT 솔루션 납품

`2025.12 ~ 2026.02` &nbsp; 24시간 실시간 상담 STT 결과 수집 · 8개 인스턴스 운영

- **무중단 배포·종료 중 데이터 유실 0건**<br/>
  수신 차단 → 대기열 소진 → 종료로 이어지는 단계적 종료 절차를 설계해, 고객사 일일 무작위 1,000건 검수에서 누락 문의 0건
- **개인정보 마스킹 정확도 80% → 98%**<br/>
  문장 단위 호출을 통화 단위로 바꿔 NLU 엔진이 문맥을 보고 판단하도록 개선

### Project 4. STT 솔루션 납품

`2025.08 ~ 2025.12` &nbsp; 상담 STT → 유형 분류 → 요약 파이프라인 · 서버 2대 운영

- **하루 2만여 건 결과 누락 장애 → 이후 누락 0건**<br/>
  기간 단위 복구 앱으로 누락분을 채우고, 결과가 누락되면 분석 엔진을 직접 재호출하는 실시간 재시도로 재발 차단
- **서버 2대 환경의 중복 처리 차단**<br/>
  락 위험이 있는 운영 테이블 인덱스 추가 대신, 전용 테이블 + `INSERT IGNORE`로 서버 간 중복을 원자적으로 판정
